# Jogo_2D
Jogo para treinar o versionamento de código.

25/08/2026- hoje configuramos a plataforma GitHub e aprendemos a colocar na unity, vimos o que é versionamento, vimos também as seis palavras do dia a dia que são: Repertório, Push, Commit, Pull, Branch e Merge. 

27/08/2026- Hoje introduzimos no assunto de Game Desing, falamos o que é e começamos a ver os seus 5 tipos, vimos um video explicativo e começamos a preencher a documentação do jogo 2D (GDD).

15/09/2026- Hoje vimos sobre Game Desaing de mecaninca para conseguirmos melhorar o nosso (GDD) e desenvolvemos uma atividade para melhor fixação.

17/09/2026- Hoje iniciamos a programação do jogo 2D, trabalhamos o movimento horizontal onde o player pode andar para frente e para atrás. 


22/09/2026 - Hoje programamos o pulo e o movimento do jogo 2D.

24/09/2026- Hoje começamos a desenvolver o mapa do jogo 2D, revisamos o código antes de começar a mexer no mapa e aqueles que estavam com erro corrigimos e começamos a fazer o mapa, iremos finalizar o resto na proxima aula.

29/09/2026- Hoje finalizamos o mapa do jogo 2D, conhecemos a Pefabs que é um atalho utilizado para ajudar na repetição de um ou mais objetos sem precisar fazer tudo do zero, fiz a utilização do Pefabs para ter um jogo mais dinâmico e assim conseguir desenvolver vários arbustos, nuvens e uma árvore.
